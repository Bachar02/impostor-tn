9 · Working demo: paper to carbon, tap to reveal, acknowledge

This demo is interactive. It shows three players on a 360 × 720 screen. It is a design reference for the reveal mechanics only, not application code, and gameplay rules still have to be checked against PRD v0.3.

Interrupting at any point returns to the neutral handoff for the current player. The role is never shown again without a new deliberate tap.
StepRule
Paper to carbonCarbon sheet slides up (520 ms). Nothing secret is rendered during the slide.
HandoffShows only the next player's name and position.
Sealed ticketOne deliberate tap on a labelled button reveals. No hold gesture.
RevealedStays until acknowledged. Acknowledge is locked for 800 ms and sits where the reveal button was not, to stop double-tap skipping.
AcknowledgeSecret content is removed in the same frame, then the next handoff appears.
